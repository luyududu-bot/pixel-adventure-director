# QA and Revision｜质量检查与修改系统

QA 先确认画面是否准确、有效、可用，再处理低价值精修。

## 质量优先级

```text
用户意图 → 最终用途 → 核心概念 → 场景母题 → 角色 → 构图 → 视觉语言 → 技术完整性 → 局部精修
```

上层未解决时不优先修下层：隐喻错误时不先修手指，H5 留白错误时不先加材质，角色身份错误时不先调粒子。

## 生成前 Gate

检查：

- **Intent**：当前需要讨论、生成还是修改；已确认决定没有遗漏。
- **Usage**：画幅、主体、留白、密度和隐喻清晰度适合载体。
- **Concept**：核心状态、Core Metaphor、Scene Motif 和最低有效冒险强度明确。
- **Character**：人物有作用，Character Lock 清楚，行动回应世界。
- **Scene**：主类型、主导空间关系、第一眼/第二眼信息和细节层级明确。
- **Visual**：像素密度、色彩职责、主光源和主焦点对比明确。

无法回答核心问题时返回对应设计层，不继续补提示词。

## 生成后三轮检查

1. **第一眼**：主体、焦点、用途、人物与环境比例、整体情绪和 Pixel Adventure Director 感。
2. **意义**：核心状态、隐喻、世界规则、人物行动、环境回应和辅助符号。
3. **技术**：身份、手脸、物件、建筑、重复、随机字符、模糊、像素尺度、发光、边缘和遮挡。

结论使用 Pass、Risk、Fail，不制造虚假精确分数。Risk 必须说明具体用途风险；Fail 返回最上游问题层。

## 问题层级

- **Intent**：完成了另一个任务；回到用户当前明确要求。
- **Core Metaphor**：漂亮但与主题薄弱、只能靠文字解释；重建核心关系。
- **Scene Motif**：隐喻没有形成清晰场面；重写“谁、在哪里、做什么、空间如何变化”。
- **Composition**：主体、比例、留白或路径错误；重组空间与焦点。
- **Character**：身份、年龄、气质、职业化或环境关系错误；返回 Character Lock。
- **Visual Language**：滤镜感、尺度混乱、幼态、平均色彩、噪点；重建轮廓、色块和光源。
- **Technical**：局部手脸、物件、随机文字、模糊或边缘错误；局部编辑。

## 编辑与重生成

局部编辑：问题区域明确、母题构图成立、修改不牵动整体、身份大体正确。必须写明保留、修改、范围和不要改变。

重新生成：Core Metaphor 或 Scene Motif 错误、世界模式选错、人与环境关系根本失效、构图与用途不兼容、角色整体重设计或像素语言根本不一致。保留有效约束，明确放弃失败策略，修改上游原因。

每轮 Revision Brief：

```text
已成立 / 真正问题 / 问题层级
必须保留 / 需要修改 / 需要删除 / 禁止新增
本轮验证目标
```

每轮只验证一个主要层级。保护用户认可的角色、母题、构图、色彩、世界规则和留白。

## 反馈转译

- “不够高级”：检查构图平均、颜色直接、角色幼态、隐喻常见、装饰过多；不自动变暗、变灰或加光效。
- “不够有感觉”：检查人与环境关系、时间节点、叙事光和母题具体性。
- “太游戏了”：检查 UI、通用职业、fantasy 覆盖现实和规则依赖任务面板。
- “太普通了”：检查是否只是现实场景像素化、缺少空间关系与规则证据。
- “太满了”：删除重复符号、降低背景对比、合并色块、建立休息区；不只缩小元素。
- “不像角色”：先查发型轮廓、年龄、比例、主色和身份锚点。

## 核心失败模式

- **Childlike Game Look**：自动 Q 版、糖果色、玩具装备；恢复成熟比例、身体重心和色彩层级。
- **Pixel Filter Scene**：普通场景只套滤镜；返回状态、空间关系和 Scene Motif。
- **PPT Metaphor**：成长=台阶、时间=时钟；通过尺度、规则、行动和情境重新赋义。
- **Meaningless Fantasy**：传送门和装备与真实状态无关；降低强度并删除无功能元素。
- **Game Symbol Pile**：等级、任务框、宝箱、钥匙竞争；保留一个机制并转为空间与行动。
- **AI Over-Enrichment**：角落全有物件、满屏粒子、结构无限复杂；删除、降对比、合并形状。
- **Wallpaperization**：氛围漂亮但无行动和规则；选择时间节点并让环境回应人物。
- **Storage Advertisement**：过度整洁陈列、像样板房；恢复使用痕迹、不完整、不对称和事件。
- **Character Posing**：人物中央摆拍、装备展示；让人物面对目标、边界或障碍。
- **Metaphor Competition**：多个强隐喻争夺画面；只保留一个主隐喻。

## 重试停止规则

同一问题在两次针对性修改后仍重复时，停止相同策略；检查提示冲突、参考冲突或工具限制，返回上一个有效设计层，改变母题、构图或编辑方式。不要把重复失败解释为“再试一次可能就好”。

## 完成标准

当用户目标完成、画幅适用、核心状态可感知、母题成立、角色正确、冒险化服务主题、像素语言统一、没有影响使用的技术错误时结束。剩余问题若只是主观微调或低价值精修，不因“还能加细节”继续修改。

交付前最终检查：用途比例、主焦点、安全区、Character Lock、Core Metaphor、World Rule、角色行动、像素尺度、色彩光线层级、生成瑕疵、无意义 fantasy、重复符号和用户认可部分是否保留。
