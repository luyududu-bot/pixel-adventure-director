# Scene System｜场景与叙事空间

Pixel Adventure Director 场景不是人物背后的背景，而是核心状态的可见结构、世界规则发生作用的地方，以及角色能够行动和选择的空间。

```text
核心状态 → 场景类型 → 场景母题 → 主导空间关系 → 角色位置与行动 → 规则证据 → 视觉路径 → 构图
```

## 场景任务与类型

场景可承担情绪、状态可视化、事件、世界观、角色关系、信息容器或系列连接，但必须有一个主要任务。

- **Atmospheric**：以光线、色彩、尺度、天气和距离传达存在状态；仍应有灯亮起、雨停止或入口打开等微弱变化。
- **State-based**：通过尺度失衡、路径、边界、重复、压缩、扩张或可见范围让内部状态可见；必须有规则。
- **Narrative**：呈现事件、选择或转折；需要动作、后果、前后痕迹、目标与障碍。
- **Hybrid**：可组合两种类型，但必须指定主类型。

## 场景母题

推荐结构：

```text
谁 + 在哪里 + 正在做什么 + 空间发生什么关键变化
```

母题应有单一主关系、清晰主体、关键行动或状态、主导空间变化，并能用一到两句话描述。

## 主导空间关系

每个场景优先选择一种主关系：

- **Scale**：人物与环境、目标或系统的尺度失衡。
- **Distance**：目标可见但遥远，人物或群体之间存在空白。
- **Boundary**：门、墙、水面、悬崖、透明隔层或光暗分界。
- **Path**：单一、分叉、循环、中断、隐藏、生成或消失的路线。
- **Elevation**：登高、下坠、俯瞰或被压在低处。
- **Enclosure**：开放与封闭、私人空间与公共空间冲突。
- **Center / Edge**：规则中心、世界边缘、群体中心与个体外围。
- **Density**：堆积、异常空白、过载或从拥挤走向开放。

空间设计应理解人物从哪里来、目标在哪里、什么阻止到达、人物能做什么、规则如何改变路径、观众先看见什么。

## 人与环境

- **Environment Dominates**：未知、巨大系统、压迫和崇高；人物虽小但需可见。
- **Balanced**：探索、选择、H5 和故事插画；行动和规则都可读。
- **Character Dominates**：身份、动作和角色海报；环境仍需参与叙事。
- **Environment Responds**：人物走过后路径点亮、触碰后空间连接、拒绝既定路线后出现新出口。这通常最能建立 Pixel Adventure Director 感。

## 焦点与视觉路径

建立 Primary Focus、Secondary Focus 和 Context。主焦点由对比、轮廓、留白、线条汇聚、光线、尺度和人物视线形成，而非单纯增加细节。

常见视觉路径：Subject → Goal、Environment → Subject、Event → Consequence、Clue → Reveal。用道路、建筑方向、光线、视线和密度引导，不依赖箭头或 UI。

## 前中远景与叙事时刻

- 前景建立入口、遮挡、尺度或包围感，不能只是大装饰。
- 中景通常承载人物、行动和母题。
- 远景显示目标、世界规模、未来路径和时间天气，细节不与主体竞争。

选择最有张力的时间节点：Before（期待与开放）、During（动作与冲击）、After（痕迹与余韵）。不要默认最激烈的时刻。

## 环境叙事与密度

用磨损、脚印、移动物件、亮灭区域、未完成结构、遗留装备、时间状态和自然痕迹让观众推断事件。线索应属于同一事件系统，不把随机杂物当丰富。

细节优先分布：主焦点最高、关键路径中等、背景低到中、休息区主动减少。高密度和低密度都需要对比区域才有意义。

## 载体适配

- **H5 / Mobile**：竖向路径、UI 与标题安全区、主体避开边缘、首屏快速理解。
- **Poster**：单一强焦点、远距离轮廓、标题区、第一眼冲击与第二眼隐喻。
- **Social**：裁切安全、缩略图识别、主体集中、控制细叙事。
- **Story Illustration**：行动、时间节点、角色关系与连续性。
- **Concept Art**：世界规则、空间规模、功能区域、气氛和探索路线。
- **Icon**：一个主体、一个轮廓、一个关系、极低细节。

## 系列连续性

保持世界规则、地理关系、色彩光线、角色身份、冒险强度和重要地点特征。每张图需有独立任务，如建立、进入、发现、冲突、选择、改变或离开。用重复但变化的地点、逐渐解锁的远景、携带物和规则痕迹连接，不只换天气和镜头。

## 问题诊断

- 像壁纸：增加明确时间节点、人物行动或环境回应。
- 很满没重点：删除和降级，建立休息区，不继续加细节。
- 漂亮但无关：检查主导空间关系是否来自核心状态。
- 人物贴背景：检查光线、尺度、脚下、动作和环境回应。
- 难理解：删除竞争隐喻，重建视觉路径和主动作。

避免所有场景都用背影看远方、无功能前景、随机道具、平均高饱和高细节、抽象无规则、H5 无留白、海报像游戏截图、Icon 塞完整故事和系列图只换背景。
