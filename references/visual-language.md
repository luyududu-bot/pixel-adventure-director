# Visual Language｜Pixel Adventure Director 像素视觉语言

Pixel Adventure Director 的像素感来自清晰形体、有意识的像素簇、稳定尺度、受控色彩、叙事光影、空间层次和选择性细节，而非简单降分辨率或马赛克滤镜。

## 成熟像素审美

成熟不等于低饱和、黑暗、冷漠、复杂或模仿老游戏。成熟感来自明确判断、克制元素、稳定比例、色彩层级、空间深度、不过度解释的情绪，以及人与环境的真实关系。画面可以明亮温暖，但避免廉价、幼态和无差别可爱化。

## Pixel Integrity

保持相近区域的逻辑像素尺寸、清晰阶梯边缘、有意识的色块和像素簇，以及人物、环境、特效的统一语言。避免平滑插画叠滤镜、人物像素而背景柔滑、多套随机像素尺度、抗锯齿与锐化混杂，以及随机方块噪声。

像素密度：

- **Low**：大像素、强轮廓、低细节；适合 Icon、缩略图和 Sprite。
- **Medium**：轮廓清晰并支持人物与环境叙事；Pixel Adventure Director 默认优先。
- **High**：适合复杂概念场景；需防止退化为普通数字插画。

除非用途要求，不固定基础分辨率，但应明确低、中或高密度。

## 形体与像素簇

```text
整体轮廓 → 大色块 → 明暗分区 → 中型结构 → 小型细节
```

主体缩小或转为剪影后仍应可辨。用大、中、小形状建立节奏；负空间用于分离主体、引导视觉、表达空旷和提供文字/UI 留位。

像素簇应解释表面转折、体积、光照、材质或运动。无明确作用的孤立噪点应删除或合并。

硬边适合主体、建筑、近景和强光暗分界；断续边适合毛发、植被、雾、破损和远景。根据光线、材质和主次使用选择性描边，避免所有物体统一粗黑边。

## 人物比例

像素风不自动等于大头短腿、超大眼睛、Q 版表情和玩具服装。用稳定头身比例、肩线、身体重心、克制面部符号和符合身份的动作保持年龄感。小尺寸可以简化，但不能无意改变年龄和气质。

## 色彩系统

建立 Dominant、Supporting、Accent 和 Neutral 的职责。强调色必须稀缺，优先用于角色身份锚点、关键行动、规则生效位置或目标。背景不必灰暗，但应降低竞争。

阴影不只是加黑，亮部不只是加白；可通过冷暖和邻近色表达时间、空气、材质、现实与概念区域。颜色数量按用途控制，新增颜色必须带来结构信息。

## 光影与特效

确定主光源、光线是否来自现实或世界规则、哪些区域应被看见、哪些保持未知、人物是否影响光。主焦点拥有最有效的明暗对比，远景逐渐压缩。

发光只用于规则证据、能量路径、角色工具、激活区域和叙事目标。限制核心光源数量，让附近物体受到光影响。避免满屏粒子、全边缘光和无来源紫蓝霓虹；光效不得覆盖像素结构。

## 空气与材质

通过远景降低对比、压缩色差、减少细节、加入像素化雾雨尘建立空间，不依赖平滑模糊。

材质差异：金属用窄强高光和硬边；石材用大体积和结构性裂缝；木材纹理顺形体；玻璃兼有反射与透视；布料褶皱随受力；植被先整体冠幅、再叶簇、最后边缘细节。材质细节不能超过物体的重要程度。

## 细节预算

```text
主体身份 → 核心行动 → 规则证据 → 视觉路径 → 环境叙事 → 材质 → 装饰
```

高密度区域旁应有安静区域。纹理只用于区分材质、显示时间、景深或规则痕迹，不均匀覆盖全图。

## 风格校准

按任务调整 Realism、Pixel Density、Mood、Adventure Intensity 和 Narrative Density，不让所有轴同时达到最高强度。Pixel Adventure Director 可借用地图、检查点、路径解锁和功能装备，但谨慎使用血条、等级、经验值、弹窗和 HUD；移除 UI 后画面仍应成立。

## 输出检查

检查意外平滑、像素尺度混乱、主体边缘模糊、噪点、发光覆盖、放大后的硬边缘、缩小后的轮廓，以及人物与场景是否属于同一美术系统。调整尺寸时优先硬边缘和整数比例缩放。

避免普通插画像素滤镜、随机像素尺寸、自动 Q 版、全图高饱和、纯黑阴影、纯白高光、无来源霓虹、随机材质噪点、远近同样清晰、复古 UI 堆叠，以及把成熟误解为灰暗。
