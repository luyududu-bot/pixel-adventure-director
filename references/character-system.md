# Character System｜角色系统

Pixel Adventure Director 角色是观众进入世界、感受状态和理解规则的入口，不是贴在背景上的人物素材。

## Character Presence

先区分三种参与方式：

- **Narrative Character｜叙事角色**：承担主体、情绪锚点、观察、选择、行动或系列连续性；需要角色风格与连续性判断。
- **Ambient Passerby｜环境路人**：只增加生活感、尺度参照、流动方向或世界运转证据；不承担关键行动，不建立身份锚点，不要求跨图统一形象。
- **No Character｜无人**：通过空间、物件、事件痕迹或缺席本身表达主题。

环境路人可以是不同场景中的学生、家长、工作人员或远处行人，但应保持低视觉权重，不能替代主角完成关键选择、触发装置或承载核心情绪。系列只需统一其总体时代、服装语汇、色彩权重和像素尺度，不统一具体面孔、发型与服装组合。用户后来要求某位路人再次出现或成为关注对象时，将其升级为叙事角色，并从此启动 First Appearance / Character Lock 流程。

如果事件痕迹或空间空缺本身更有力量，或用户要求纯环境、Icon/抽象视觉不适合人物，则可以无人。

判断：删除人物后画面意义是否仍完整？若完全不受影响，人物可能只是装饰。

## 角色来源与优先级

1. 用户提供的角色参考图。
2. 前序画面或对话已确认角色。
3. 用户文字设定。
4. 为当前任务创建的新角色。

不得把已有角色当新角色重做。参考图只提取可见的轮廓、发型、年龄感、比例、服装结构、主色、标志物和气质；不推断私人身份，不把光照色误当固定色，也不擅自增加背景故事。
## Character Lifecycle｜角色生命周期

先判断角色处于哪个阶段：

1. **No Character**：画面无需人物，不启动角色流程；
2. **Ambient Passersby Only**：只有非连续环境路人，不启动角色风格、Character Lock 或设定板流程；
3. **First Appearance**：为当前项目新增叙事角色，首次生成前完成一次人物风格引导；
4. **Second Appearance Without Sheet**：用户第二次希望继续使用首张场景中的同一叙事角色，但尚无角色形象设定板；先生成设定板并建立 Character Lock，再进入第二个场景；
5. **Locked Recurring Character**：已有合格设定板或用户提供的正式角色设定，直接按其复用，不重复风格访谈。

“第二次”指同一项目中，已经有一张包含该人物的生成结果，用户又提出“继续用这个人”“沿用上一张角色”或要求该人物进入另一个场景。对同一张图做局部修改不算第二次出场，不触发设定板门槛。

### First Appearance｜首次人物风格引导

如果要新增人物，在现有 Clarification Batch 中完成一次风格引导，不单独开启连续访谈。提供 2–3 个解释结果差异的设计方向，例如：

- **A｜现实学生型**：自然头身与当代服装，主要靠姿态和色块建立成熟感；
- **B｜轻冒险转译型**：现实身份清晰，增加少量与行动有关的功能层或装备；
- **C｜世界融合型**：轮廓、服装结构或能力与概念世界规则深度连接。

根据用途和冒险强度动态改写选项，可将合理推荐方向放在 A；不要把固定发型、眼睛颜色、鞋款和小配件拆成多轮问题。用户已有文字设定或参考图时，先提取其中已确定的风格，不重复询问。完成后记录一个最小的 Provisional Character Lock：年龄感、头身比例、核心轮廓、发型方向、主色、服装结构、身份锚点和冒险化等级。

风格引导每个新角色只做一次。除非用户主动重设人物或现有信息发生冲突，后续不得重复让用户选择同一组角色风格。

### Character Design Sheet Gate｜人物形象设定板门槛

当同一人物将第二次出现在新的画面或场景中，且还没有合格设定板时：

1. 明确说明为了保持人物一致性，先完成一张人物形象设定板；
2. 优先使用首张场景中的人物图作为 Character Reference；若该图当前不可用，引导用户重新上传，不只凭文字记忆重造；
3. 生成中性背景的像素人物设定板，至少包含全身正面、四分之三视图、侧面或背面中的三个稳定视图，以及头像／发型细节、固定色板、服装分层和标志配件；
4. 不加入场景叙事、戏剧性透视、强环境光、临时道具或会遮挡身份的动作；
5. 同时整理文字版 Character Lock，区分 Hard Lock、Soft Lock、Free Variables 与 2–4 个 Identity Anchors；
6. 设定板完成后，将它作为后续场景的最高优先级 Character Reference，再继续第二张场景。

如果用户已经提供正式角色设定板，检查它是否足以锁定身份；足够时直接登记并跳过重新生成。若只有一张复杂场景图，仍应先从该图提炼并生成干净设定板。

设定板是角色连续性资产，不计入常规需求访谈轮次。需要用户补传上一张人物图时，把这一项与尺寸、UI 或其他素材要求集中说明，不连续追问。

## Character Lock

- **Hard Lock**：核心发型轮廓、主要发色、年龄感、身体比例、标志轮廓、用户要求保留的服装/配件。未经同意不得改变。
- **Soft Lock**：服装材质、外套和装备层、功能配件、局部整理、环境光下的颜色变化。可适配但保持气质。
- **Free Variables**：动作、镜头、临时工具、环境光和非身份装饰。

像素画优先保留 2–4 个高识别度 Identity Anchors：独特轮廓、发型、稳定色块、服装结构、标志配件或身体语言。人物缩小时先保轮廓和色块，再保面部细节。

## Character DNA

仅在长期角色中记录实际会影响未来生成的信息：

- **Visual DNA**：轮廓、发型、比例、固定色彩、服装结构、标志物。
- **Temperament DNA**：谨慎/主动、理性/直觉、观察型/行动型等，并通过姿态表现。
- **Action DNA**：面对未知时先观察、行动、保护、修复、寻找规则或拒绝既定路径。
- **Narrative DNA**：当前阶段、欲望、限制、主要冲突和已发生变化。
- **Relationship DNA**：仅在长期人物关系中记录引导、保护、张力和典型距离。

一次性人物不建立庞大 Character DNA。

## 新角色创建

仅在用户要求、场景必须通过人物行动成立、没有已有角色且允许设计时创建。先完成一次 First Appearance 风格引导，再解决角色功能、年龄与比例、轮廓发型、主色与服装结构、身份锚点、面对世界的行动方式；不要从复杂身世和大量装饰开始。

## 角色冒险化等级

角色改造强度与世界冒险强度相互独立。概念世界不要求角色彻底变装。

- **Level 0 / Original**：保持现实角色，只调整姿势、表情和光线。
- **Level 1 / Functional Layer**：增加少量与行动有关的功能配件。
- **Level 2 / Role Translation**：把现实身份转译为冒险身份，但保持 Character Lock。
- **Level 3 / World Integration**：服装、身体或能力与世界规则深度连接。

不得无理由改变年龄、性别表达、身材、肤色、核心发型、气质、文化特征和既有人物关系。需要改变 Hard Lock 时先询问。

## 角色行动与姿态

动作应回答角色如何回应世界：进入、观察、选择、攀登、穿越、修复、抵抗、保护、解读、等待、回望或离开。避免无目的站立、对镜头摆姿势和无关武器。

小尺寸像素画优先通过身体重心、肩部、头部角度、手部位置、与边界的距离、朝向和环境回应表达情绪，而非依赖面部。

## 尺度与多角色

- 大人物适合身份、表情和角色海报，但会削弱世界规模。
- 平衡比例适合人物与环境共同叙事。
- 小人物适合巨大世界、未知、压迫和探索，需用轮廓、主色与位置保持识别。

多角色先确定同行、引导、保护、对抗、分离、追随或群体与个体的主关系，再通过距离、高低、朝向、视线和动作呼应表达。不得平均分配视觉权重。

## Character Card

当角色第二次进入新场景、用户要求长期管理或系列要求严格一致时建立。第二次出场前若没有人物形象设定板，先执行 Character Design Sheet Gate：

```text
名称 / 作用 / 当前阶段
Hard Lock / Soft Lock / Identity Anchors
Visual DNA / Temperament DNA / Action DNA
当前冒险化等级 / 世界身份
允许变化 / 禁止变化 / 已出现的场景
```

系列一致性优先级：身份锚点、年龄和比例、发型轮廓、主色和服装结构、气质与行动方式、合理光色变化、临时装备。允许镜头、姿势、天气和叙事阶段变化；一致性不等于复制姿势。

## 问题诊断

- 不像同一人：先查发型轮廓、年龄、比例、主色和身份锚点。
- 太普通：检查轮廓、行动和功能，而非直接加配件。
- 太像游戏职业：降低装备权重，回到现实原型。
- 像贴在背景上：检查脚下、手中、视线、光线和环境回应。

避免默认背影人物、自动添加斗篷武器、改变年龄身材、依赖小细节、多人无主次，以及为一次性人物建立庞大档案。
