# Adventure System｜冒险化转译系统

冒险化不是添加 fantasy 装饰，而是改变空间、尺度、行动或因果关系，让观众通过世界规则感受到真实状态。

```text
现实经验 → 核心状态 → 核心张力 → 核心隐喻 → 场景母题 → 世界规则 → 角色行动 → 可见证据
```

## 冒险化开关

倾向开启：用户明确要求冒险转译；抽象状态难以通过现实场景表达；用户希望更强象征性；主题包含探索、转折、升级或未知；世界化能建立更有意义的人与环境关系。

倾向保持现实：用户要求真实日常；主题来自细微生活瞬间；冒险化会削弱可信度；用途要求快速传递现实信息；具体画面无需规则变化。

若冒险化会根本改变结果则询问；仅是轻度气氛转译时使用最低有效强度。

## 强度等级

- **Level 0 / None**：现实结构不变，只用构图、光影、色彩、天气和现实动作。
- **Level 1 / Light**：现实仍可辨，只有一个有意义的异常，如道路逐渐变成尚未解锁的地图。
- **Level 2 / Medium**：现实与冒险结构共同存在；身份、物件、障碍或空间形成统一系统。
- **Level 3 / High**：现实经验完整转译为概念世界，如压力变成改变重力的系统。

强度取决于现实结构被改变多少，不取决于奇幻物件数量。

## 世界模式

- **Reality Translation**：原生活场景仍可辨，适合 H5、活动页、校园主题和快速理解。
- **Concept World**：世界主要由主题隐喻规则构成，适合概念视觉、艺术创作和强隐喻海报。
- **Hybrid World**：现实入口通向概念空间，或概念规则逐渐侵入现实；必须有清晰过渡逻辑。

## 核心状态

不要把“成长”“压力”等抽象词直接当最终主题。寻找：人物想要什么（Desire）、被什么限制（Constraint）、核心冲突（Tension）、正在发生什么转变（Transition）、人物拥有什么行动能力（Agency）。优先选择能产生空间关系和角色行动的状态。

## 核心隐喻

核心隐喻是决定世界如何运行的关系，而非装饰符号。可从以下维度寻找：

- Scale：过大、过小或持续变化。
- Distance：目标可见却难以抵达。
- Boundary：门、墙、悬崖、透明隔层。
- Path：分叉、循环、中断、隐藏或生成。
- Gravity：被压住、漂浮、下坠或逆向生长。
- Time：冻结、循环、堆积、加速或错位。
- Repetition：任务、房间或台阶持续复制。
- Material：坚硬、脆弱、透明、流动或风化。
- Light：遮挡、点亮、追随人物或揭示路径。
- System：分类、测量、评分、装配、加载或重置。

隐喻应通过 Fidelity、Visuality、Actionability、Coherence、Specificity 和 Usage Fit 检查。只能靠口号解释的隐喻通常还不够视觉化。

## 场景母题

推荐结构：

```text
一个角色 + 一个关键行动 + 一种主导空间关系 + 一个正在发生的世界变化
```

母题应能用一到两句话描述，形成明确主焦点，支持人物行动，不依赖大量辅助符号。

## 世界规则

稳定规则包含：Cause（什么触发）、Behavior（世界如何变化）、Limit（规则边界）、Evidence（如何看见）、Response（人物如何利用、抵抗或改变）。最终画面无需解释全部规则，但设计时必须理解。

角色应进入、探索、攀登、修复、抵抗、适应、选择、保护或转化世界，而不是站在画面中央摆姿势。

## 隐喻清晰度

- **Clear**：H5、产品页和快速传播；一个易读关系、明确行动、少量线索。
- **Balanced**：海报、社交和故事插画；第一眼成立，第二眼发现隐喻。
- **Poetic**：艺术与概念视觉；允许开放解释，但规则仍一致。

辅助符号只用于解释主规则、引导视觉路径、显示事件痕迹或建立连续性。控制门、钥匙、时钟、齿轮、地图、宝箱、光球和任务面板的叠加。

## 失败模式

- Generic Gamification：现实场景叠加 UI，空间和人物没有变化。
- Symbol Pile：多个常见隐喻没有主次。
- Decorative Fantasy：奇幻元素与真实状态无关。
- PPT Metaphor：抽象词直接替换成常见图标。
- Over-Transformation：现实经验被彻底遮蔽。
- Passive Character：人物没有选择或回应。
- Rule Inconsistency：不同区域遵循冲突规则。
- Meaningless Abstraction：抽象来自缺少关系，而非诗意。

检查：真实状态是什么、核心张力是什么、冒险化是否有帮助、最低有效强度是多少、人物能做什么、规则如何可见、母题能否一两句话说清楚。
